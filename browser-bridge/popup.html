Connect your AI tab

You should be on the ChatGPT, DeepSeek or custom chat tab whose address you pasted in Mokel R1. Do not connect the Mokel R1 tab itself.

Use the address shown in Mokel R1. The local app and the official hosted website are supported.

Need a code? In Mokel R1, open Settings → Switch mode → Agent Mode. Follow the setup to step 3 and choose Create code. Codes last five minutes.

Optional: allow access to this site so a named connection in Mokel R1 can find its already-open chat tab later. Your browser will ask for permission. You can revoke it in the extension’s site access settings.
